What the points system handles

The Google Form is the check-in screen. The private master workbook verifies each response, prevents duplicate credit, and publishes only the safe fields needed by this page.

📝

Verified check-ins

Members submit their OSU name.number and event ID through the form.

⚙️

Automatic scoring

The workbook looks up the approved event type and point value.

🛡️

Duplicate protection

Only the first valid check-in for a member/event pair earns points.

🔒

Privacy-safe display

Private names, email addresses, and name.number values never enter the public export.

🔎

Officer review

Invalid or duplicate submissions go to a review queue instead of silently earning credit.

📚

Audit trail

Point Log and Adjustments preserve the reason for every score change.

How It Works

1

Check in

Use the event Google Form and enter your OSU name.number. First-time members choose either full name or first name plus last initial for public display.

2

Sheet verifies

The private workbook checks the roster, event, and duplicate rule. Exceptions go to the officer Review Queue.

3

Dashboard updates

Valid points roll into Member Totals, the member dashboard, and the privacy-safe Website Export. The page reads that export only.
